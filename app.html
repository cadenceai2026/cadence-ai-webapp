HOW TO GET YOUR ACCESS TOKEN
1. Go to strava.com/settings/api
2. Open this URL replacing YOUR_ID: strava.com/oauth/authorize?client_id=YOUR_ID&response_type=code&redirect_uri=http://localhost&scope=activity:read_all
3. Authorize → copy the code from the redirect URL
4. Open browser console (F12) and run the fetch command to get your access_token
